# Simulado comentado – Microsoft Azure AI-103

Apresentação da live de resolução comentada de questões para o exame **AI-103: Developing AI Apps and Agents on Azure**, da certificação *Microsoft Certified: Azure AI Apps and Agents Developer Associate*.

> **Aviso:** conteúdo independente, feito para estudo. As questões vêm de simulados particulares, foram revisadas com a documentação oficial do Microsoft Learn e **não são questões oficiais nem vazadas** do exame.

## O que tem na apresentação

📥 [Baixar a apresentação (Azure-AI-103-Simulado-Comentado.pptx)](Azure-AI-103-Simulado-Comentado.pptx)

- **30 questões de cenário**, distribuídas pelos 5 domínios oficiais na proporção dos pesos da prova.
- Para cada questão: o enunciado com as informações decisivas em destaque, a resposta correta, o conceito cobrado, uma dica de prova e a análise de **todas** as alternativas.
- Referência oficial do Microsoft Learn em cada resolução.
- Revisão final com as associações que mais caem e os pontos de atenção sobre mudanças recentes no Microsoft Foundry.

## Distribuição das questões

| Domínio oficial | Peso na prova | Questões na apresentação |
|---|---|---|
| Planejar e gerenciar uma solução de IA do Azure | 25–30% | 1 a 8 |
| Implementar soluções de IA generativa e agênticas | 30–35% | 9 a 18 |
| Implementar soluções de extração de informações | 10–15% | 19 a 22 |
| Implementar soluções de visão computacional | 10–15% | 23 a 26 |
| Implementar soluções de análise de texto | 10–15% | 27 a 30 |

Domínios e pesos conforme o *skills measured* vigente (16/04/2026).

## Como estudar com este material

1. Responda cada questão **antes** de avançar para o slide de resolução.
2. Leia a análise de todas as alternativas, não só da correta: é ali que estão as diferenças entre serviços que a prova explora.
3. A cada erro, abra a referência oficial indicada no slide.

## Como os gabaritos foram revisados

As 30 questões saíram de um conjunto de 300 questões de 6 simulados. Cada gabarito foi conferido com o Microsoft Learn. Uma questão (a de número 6, sobre guardrails) teve o gabarito corrigido: no Foundry atual, o nível de bloqueio **High** é o mais restritivo, ao contrário do que diz parte dos materiais antigos.

O Azure muda rápido. Se encontrar algo desatualizado, abra uma *issue* citando a página do Microsoft Learn.
